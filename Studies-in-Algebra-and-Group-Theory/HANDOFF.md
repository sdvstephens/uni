### Preamble — MUST READ BEFORE ANY EDITING

The preamble at `~/university/preamble.tex` is ~1350 lines and defines ALL custom commands. You MUST check it before writing any LaTeX. Key commands:

**Theorem environments** (tcolorbox-based, all take `{Title}{content}`):
- `\thm{Title}{content}` — Theorem (blue border)
- `\dfn{Title}{content}` — Definition (red title bar)
- `\mprop{Title}{content}` — Proposition
- `\cor{Title}{content}` — Corollary  
- `\mlemma{Title}{content}` — Lemma
- `\ex{Title}{content}` — Example
- `\qs{Title}{content}` — Question
- `\mer{Title}{content}` — Exercise
- `\pf{Title}{content}` — Proof (myproof environment)
- `\nt{content}` — Note box
- `\begin{solution}...\end{solution}` — Solution environment

**CRITICAL BUG:** The `\CC`, `\RR`, `\ZZ`, `\QQ` macros accept an optional `[n]` argument (e.g., `\RR[3]` → ℝ³). This means `\CC[z_1, ..., z_n]` gets parsed as `\CC` with optional arg `z_1,...,z_n`, producing `ℂ^{z_1,...,z_n}` instead of `ℂ[z_1,...,z_n]`. **ALWAYS brace these:** `{\CC}[z_1,...,z_n]`.

**Math operators** (all via `\DeclareMathOperator`):
`\Img`, `\Ker`, `\rank`, `\Tr`, `\Hom`, `\End`, `\Sym`, `\sgn`, `\Aut`, `\Stab`, `\Inn`, `\GL`, `\diag`, `\ord`, `\lcm`

**Other key commands:**
- `\ol{x}` → overline
- `\id` → "id" in text mode
- `\RR`, `\CC`, `\ZZ`, `\QQ`, `\FF` — blackboard bold (with optional `[n]` for power)
- `\lecture{N}{Title}` — starts a chapter

**Packages loaded:** tikz, tikz-cd, tikz-3dplot, braids (via `\usetikzlibrary{braids}`), mhchem, chemfig, hyperref, tcolorbox, and many more.

**`\tr` is NOT a valid command** — use `\Tr` (this was a recurring bug in early sessions).

### Compilation Pipeline

1. `compile-lectures Studies-in-Algebra-and-Group-Theory` → calls `compile_master.py`
2. Script auto-generates `master.tex` with `\input{lecture_01}` through `\input{lecture_13}`
3. Uses `docmute` package to strip each lecture's standalone preamble
4. Runs `latexmk -pdf -f` (force mode to push past non-fatal tcolorbox/hyperref warnings)
5. Output: `.latexmk/out/master.pdf`
6. If return code ≠ 0 but PDF exists → prints "⚠️ Compiled with warnings" instead of failing

**Known compilation warnings:** 
- `Missing { inserted` / `Missing } inserted` around line 891 of lecture_09.tex — a tcolorbox/hyperref interaction in the orthogonal operators proof. Non-fatal, PDF renders correctly.
- `page.1 duplicate` — front matter pagination, harmless.

## Detailed Content Summary Per Lecture

### Lecture 01 — Set Theory
Ordered pairs, relations, functions, families, inverses, composites.

### Lecture 02 — Group Theory Basics
Axioms, group variants, fundamental examples (Z/n, S_n, GL_n), direct products, subgroups, generated subgroups, cyclic groups, homomorphisms, isomorphisms, order of elements.

### Lecture 03 — Group Relations
Quotient groups, cosets, normal subgroups, group actions, Cayley's theorem, isomorphism theorems (1st/2nd/3rd), correspondence theorem, symmetric group (cycle structure, conjugacy, sign homomorphism, alternating group), exact sequences, free groups, presentations.

### Lecture 04 — Vector Spaces and Linear Algebra
Ring/field homomorphisms, polynomial rings, field extensions, formal power series, Laurent series, characteristic, vector spaces, subspaces, direct sums, span/independence/basis, dimension, change of basis, similarity, trace/det invariants, kernel/image, rank-nullity, duality (dual space, dual basis, dual maps, transpose), double dual, annihilators, quotient spaces, endomorphisms, invariant subspaces, eigenvalues, diagonalizability.

### Lecture 05 — Linear Maps
Matrix representation, Hom(V,W) ≅ M_{m×n}(k), change of basis.

### Lecture 06 — Kernels, Images, and More
Bézout's identity, Z/p is a field, root bound theorem, vector spaces, finite-dimensional spaces, linear maps, matrix representation.

### Lecture 07 — More Maps and Spaces
Generalized eigenspaces, nilpotent operators, primary decomposition, Jordan normal form, minimal/characteristic polynomials, Cayley-Hamilton.

### Lecture 08 — Categories: An Interlude
Category axioms, examples (Set, Grp, Vect_k, posets), isomorphisms, automorphism groups, groupoids, products/coproducts via universal properties, examples across categories.

### Lecture 09 — Inner Product Spaces + Tensors (LARGEST FILE)
Bilinear forms (matrix rep, dual space connection, rank, nondegeneracy), inner products (real), Hermitian inner products (complex), norms, Cauchy-Schwarz, orthogonality/complements, Gram-Schmidt, orthogonal projections, adjoint operators, self-adjoint/normal operators, spectral theorems (real + complex), orthogonal/unitary operators (characterizations, reflections, products of reflections, classical matrix groups O(n)/SO(n)/U(n)/SU(n), structure of orthogonal operators), Hermitian forms and real forms.

**Tensors section:** Three definitions of tensor product (bases, quotient, universal property with tikzpicture commutative triangle), basic identities, Hom ≅ V*⊗W, tensor algebra, symmetric powers (Sym^d, averaging operator, polynomial ring isomorphism), exterior powers (∧^d, wedge product, graded-commutativity, linear independence detection), trace as contraction, determinant via ∧^n, characteristic polynomial via exterior powers.

**Tensor calculus interlude:** Type (r,s) tensors, Einstein summation, transformation law, tensor fields on manifolds, metric tensor, Einstein field equations, index gymnastics (raising/lowering/contraction), Riemann → Ricci → scalar curvature chain.

### Lecture 10 — Modules and F.G. Abelian Groups
Module definition, examples (Z-modules = abelian groups, R as module, k[x]-modules from endomorphisms, restriction of scalars), submodules, ideals, PIDs, quotient modules. "Nothing is true" section (no bases, independence ≠ basis, spanning ≠ basis, non-f.g. submodules). Module homomorphisms.

Classification theorem for f.g. abelian groups with full proof: Step 1 (presentation as Z^n/Im(T) via free submodule lemma), Step 2 (Smith Normal Form with divisibility/primitive elements lemma and inductive proof), Step 3 (assembly). Examples of small order. Exercises with solutions.

### Lecture 11 — Group Actions, Conjugacy, Sylow
Orbits, stabilizers, faithful/transitive actions, conjugate stabilizers, orbit-stabilizer theorem (full proof), coset action, Burnside's lemma (double-counting proof), tetrahedron coloring example.

Left multiplication → Cayley, conjugation → class equation, groups of order p² are abelian, 5 groups of order 8.

Sylow theorems (all three, full statements). Finite subgroups of SO(3) (pole-counting, case analysis → Z/n, D_n, A_4, S_4, A_5 with tikz polyhedra).

Conjugacy in S_n (cycle type = partition), class equations for S_3/S_4/S_5, normal subgroups of S_4. Alternating group (A_n generated by 3-cycles, class splitting in A_n, A_5 class equation, simplicity of A_5 and A_n for n≥5, normal subgroups of S_n corollary).

**Sylow proofs** (all three): combinatorial lemma, stabilizer-divides-subset lemma, existence via action on p^e-subsets, conjugacy via K-action on cosets, s_p ≡ 1 via H-conjugation on Sylow set. Normalizers. Cauchy's theorem as corollary.

**Semidirect products:** definition, recognition criterion, direct product criterion, S_3 ≅ Z/3 ⋊ Z/2, D_n ≅ Z/n ⋊ Z/2. Classification of groups of order 12 (all 5) and order 21 (both).

### Lecture 12 — Generators, Presentations, Cayley Graphs
Free groups, finitely presented groups, word problem (Novikov-Boone undecidability). Cayley graphs with tikz diagrams (Z number line, S_3 hexagon). Word length, inversions in S_n, S_4 as permutohedron. Growth rate (polynomial vs exponential, Gromov's theorem).

Braid group B_n (presentation, tikz braid diagrams for generators and Yang-Baxter relation, surjection to S_n, pure braids, Markov's theorem, Garside normal form).

SL_2(Z) (generators S and T, Euclidean algorithm proof). PSL_2(Z) ≅ Z/2 * Z/3 (full proof via word reduction + nonneg matrix argument, tikz fundamental domain diagram). Alternative presentations, B_3 → PSL_2(Z) central extension.

### Lecture 13 — Representation Theory
Definitions (representation, subrepresentation, irreducible). Cyclic group reps (diagonalizable, n roots of unity). Abelian group reps (simultaneous diagonalization, all 1-dim). Dual group. Homomorphisms (G-equivariant maps), constructions (⊕, ⊗, V*, Hom, quotient).

Maschke's theorem (two proofs: invariant inner product + averaging projection). Complete reducibility. Failure cases (char p, infinite groups).

Schur's lemma (both parts). Center acts by scalars. Irreducible reps of S_3 (U, U', V with irreducibility proof).

Characters (definition, class functions, all properties including χ_{V⊗W}, χ_{V*}, χ_{∧²V}). Symmetric polynomials digression (elementary/power sums, fundamental theorem).

Character orthogonality (averaging projection, Hermitian inner product H, orthonormality theorem). Corollaries (#irreducibles = #conjugacy classes, character determines rep, H(χ,χ)=1 criterion). Regular representation (each V_i appears dim(V_i) times, Σ(dim V_i)² = |G|).

Character tables: S_3 (3×3), S_4 (5×5, finding W via V⊗V), A_4 (4×4 with ω = e^{2πi/3}). Exercises with solutions.
